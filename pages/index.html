path-coverage schemas

The JSON Schemas (draft 2020-12) of the two files every language's path coverage tool writes at the end of a run.

v3

  • path_coverage.schema.json: the counts, each a tally by test, for AIs and other tools.
  • path_coverage.source.schema.json: what drawing each file's code needs.

v2

As v3, with each count a bare number, not split by test.

  • path_coverage.schema.json: the counts, for AIs and other tools.
  • path_coverage.source.schema.json: what drawing each file's code needs.

v1

As v2, with each flow named a card, under cards.

  • path_coverage.schema.json: the counts, for AIs and other tools.
  • path_coverage.source.schema.json: what drawing each file's code needs.

Source: github.com/path-coverage/schemas
